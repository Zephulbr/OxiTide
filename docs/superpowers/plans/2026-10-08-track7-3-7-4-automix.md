# Track 7.3 + 7.4 — Smart and Beat-Matched Transitions Implementation Plan

**Goal:** Phase 1 (silence trim + cross-format overlap) and Phase 2 (beat-matched alignment) of AutoMix, each behind its own toggle, with per-transition reports for A/B testing.

**Spec:** `docs/superpowers/specs/2026-10-08-oxitide-track7b-automix-design.md`

## Global Constraints

- Pure Rust only (AM-D2): `rustfft` 6, `rubato` 0.16; record both in `THIRD_PARTY_NOTICES.md`.
- With all new toggles off, the Track 7 crossfade/gapless behavior and its tests stay unchanged.
- Every task keeps `cargo test --workspace`, `cargo clippy --workspace -- -D warnings`, `npm --prefix ui run check`, and `npm --prefix ui test` green before its commit.

### Task 1: Settings and report types

- [ ] `CrossfadeSettings`: `trim_silence`, `resample`, `beat_match` (serde default false).
- [ ] `automix.rs`: `TransitionKind`, `TransitionReport` (serde), `TransitionPlan`.

- [ ] `audible_bounds`; onset envelope (decimate → STFT → spectral flux → detrend).

- [ ] Synthetic-signal tests (90/128/174 BPM, noise, sustained chords).

- [ ] `plan_transition` (trim, beat alignment with octave handling, drift-bounded beat counts, fallbacks with reasons).
