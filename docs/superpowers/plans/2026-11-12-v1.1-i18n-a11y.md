# v1.1.0 — i18n + a11y follow-up Implementation Plan

> **For agentic workers:** steps use checkbox (`- [ ]`) syntax for tracking. Phase 1 is detailed;
> later phases are task lists that are expanded when they start.

**Goal:** ship v1.1.0 from `release/1.x` with a translatable UI, 23 machine-drafted languages,
a correction/volunteer workflow, and the A-1–A-5 accessibility items.

**Spec:** `docs/superpowers/specs/2026-11-12-oxitide-v1.1-i18n-a11y-design.md` (section numbers
below are the spec's).

**Branch:** `release/1.x` (commit there directly or on short branches off it); merge forward into
`main` after each phase lands (`docs/release.md`, "Branches").

## Global constraints

- Svelte 5 runes only; semantic tokens only; no mode branching; zero `svelte-ignore`.
- Every task keeps `npm --prefix ui run check` and `npm --prefix ui test` green; tasks touching
  Rust also keep `cargo fmt --all -- --check`, `cargo test --workspace` and
  `cargo clippy --workspace --all-targets -- -D warnings` green.
- Existing component tests keep querying English text; the default language in tests is `en`.
- New commands: `generate_handler!`, `SYNC_COMMANDS` (with the reason) or `async`, and the remote's
  `NOT_EXPOSED`.
- No network in scripts, CI or runtime for translation (spec §7.3).
