# v1.1.0 — i18n + a11y follow-up Implementation Plan

> **For agentic workers:** steps use checkbox (`- [ ]`) syntax for tracking. Phase 1 is detailed;
> later phases are task lists that are expanded when they start.

**Goal:** ship v1.1.0 from `release/1.x` with a translatable UI, 23 machine-drafted languages,
a correction/volunteer workflow, and the A-1–A-5 accessibility items.

**Spec:** `docs/superpowers/specs/2026-11-12-oxitide-v1.1-i18n-a11y-design.md` (section numbers
below are the spec's).

**Branch:** `release/1.x` (commit there directly or on short branches off it); merge forward into
`main` after each phase lands (`docs/release.md`, "Branches").

## Global constraints

- Svelte 5 runes only; semantic tokens only; no mode branching; zero `svelte-ignore`.
- Every task keeps `npm --prefix ui run check` and `npm --prefix ui test` green; tasks touching
  Rust also keep `cargo fmt --all -- --check`, `cargo test --workspace` and
  `cargo clippy --workspace --all-targets -- -D warnings` green.
- Existing component tests keep querying English text; the default language in tests is `en`.
- New commands: `generate_handler!`, `SYNC_COMMANDS` (with the reason) or `async`, and the remote's
  `NOT_EXPOSED`.
- No network in scripts, CI or runtime for translation (spec §7.3).

## Phase 1 — Pipeline end to end

### Task 1: Dependency and catalogs scaffold

**Files:** `ui/package.json`, `ui/package-lock.json`, `ui/src/locales/**`, `ui/tsconfig.json`
(if `resolveJsonModule` is off), `THIRD_PARTY_NOTICES.md`.

- [ ] `npm --prefix ui install intl-messageformat` (runtime dependency; BSD-3-Clause, add to
      `THIRD_PARTY_NOTICES.md`).
- [ ] Create `locales/languages.json` with the 24 rows of spec §3 (`code`, `endonym`, `script`:
      `latin` / `cyrillic` / `greek` / `ja` / `ko` / `zh-Hans` / `zh-Hant`).
- [ ] Create `locales/en/{app,remote,shell}.json`, `locales/notes/{app,remote,shell}.json`,
      `locales/glossary.json` (terms and do-not-translate list from spec §4.6 / §6.2).
- [ ] Seed `en/app.json` with the first extracted area's keys (Task 6) and `en/shell.json` with the
      tray/taskbar strings.

### Task 2: `lib/i18n.svelte.ts`

**Files:** create `ui/src/lib/i18n.svelte.ts`, `ui/src/lib/i18n.test.ts`,
`ui/src/lib/languages.ts` (matching), `ui/src/lib/languages.test.ts`.

- [ ] `matchLanguage(preferred: readonly string[], shipped): string` per spec §3 (zh scripts via
      region, `pt-*`, `no`/`nn`, base language, `en`). Tests cover every rule.
- [ ] `i18n` singleton: `language` (`$state`), `setLanguage(code)` (await chunk via
      `import.meta.glob("../locales/*/app.json")`, then set), `t(key: MessageKey, params?)`
      with a per-language `IntlMessageFormat` cache, English fallback for a missing key.
- [ ] `MessageKey` = `keyof typeof en` from `../locales/en/app.json`.
- [ ] Tests: formatting with params; `plural` in `pl` (one/few/many/other) and `ja` (other);
      fallback; a switch re-renders a `$derived` reader.

### Task 3: Boot and mirror

**Files:** `ui/index.html`, `ui/src/main.ts`, `ui/src/lib/theme.ts` (mirror key helper).

- [ ] Inline script reads `oxitide.language` and sets `document.documentElement.lang` (unknown →
      skip).
- [ ] `main.ts`: `await i18n.setLanguage(mirror)` before `mount` when the mirror is not `en`
      (failure → English).
- [ ] `i18n.setLanguage` writes the mirror and `<html lang>`.

### Task 4: Config, commands and the picker

**Files:** `crates/oxitide-app/src/config.rs`, `commands.rs`, `main.rs`, `remote/rpc.rs`,
`ui/src/lib/api.ts`, `ui/src/lib/appearance.svelte.ts` (or a small `lib/language.svelte.ts`),
`ui/src/views/Settings.svelte`, `ui/src/lib/settingsIndex.ts`.

- [ ] `UiConfig.language: String` (default `"system"`), round-trip test; unknown values are kept
      on disk but treated as `"system"` by the UI.
- [ ] `set_language(language)` (sync, persists) and `set_shell_language(code)` (sync, applies
      shell text, Task 5); both in `generate_handler!`, `SYNC_COMMANDS`, `NOT_EXPOSED`.
- [ ] UI: on config load, resolve (`"system"` → `matchLanguage(navigator.languages)`), call
      `i18n.setLanguage`, then `set_shell_language`.
- [ ] Settings → Appearance → Look & feel → **Language** row (`data-setting="language"`): a
      `Select` with "System (<endonym>)" and every language by endonym + status tag; the
      **Help translate** link. Settings index entry `language` with keywords.
- [ ] Switching clears `viewCache`.

### Task 5: Rust shell text

**Files:** create `crates/oxitide-app/src/shell_text.rs`; modify `tray.rs`, `thumbbar.rs`,
`state.rs` (current shell language), `main.rs` (mod).

- [ ] `include_str!` every `ui/src/locales/<code>/shell.json` (a `build.rs`-free static table
      generated by a macro list; a test asserts the list equals `languages.json`'s codes).
- [ ] `shell_text::get(lang, key) -> &str` with English fallback; parsed once (`OnceLock`).
- [ ] Tray items keep their `MenuItem` handles in `AppState`; `set_shell_language` calls
      `set_text` on each. Thumb-button tips take the language and are re-pushed on a switch.
- [ ] Tests: lookup/fallback, completeness against English, thumbbar `buttons()` tips per
      language.

### Task 6: First extraction slice (proves the pipeline)

- [ ] Extract `lib/titles.ts` (route titles), the skip link, `ToastHost`/toasts in
      `lib/toasts.svelte.ts` callers that are shared, and `PlayerBar.svelte`'s transport labels.
- [ ] Update `titles.test.ts` to run through `t()` in `en`.

### Task 7: Scripts

**Files:** `scripts/i18n/{lib.mjs,check.mjs,status.mjs,apply-draft.mjs,sync.mjs,review-sheet.mjs,pseudo.mjs}`,

### Task 8: Phase 1 verification

## Phase 2 — Extraction by area (spec §14.2)

One task per area, each ending with the pseudo-locale walk of that area clean and gates green:

1. Shell: `App.svelte`, `Sidebar.svelte`, `WindowControls.svelte`, dialogs
   (`ConfirmDialog`, `CollectionDialogs`, `CollaboratorsDialog`, `PlaylistPicker`), `Modal`
   titles, `EmptyState`/`ErrorState`/`Loading`, `KeyringNotice`, `ToastHost`.
2. Lists and menus: `TrackTable`, `QueueRail`, `ContextMenu` and `nativeContextMenu`,
   `SortBar`/`SortSelect` and the `*Sort.ts` label tables, `TrackFilter`, selection
   announcements.
3. Pages: Home, Explore + search, Feed, Album, Artist, ArtistAll, Playlist(s), Mix(es), Radio,
   Section, TidalPage, Collection*, SaveForLater, Profiles, Purchases, Login, NowPlaying, Mini,
   LyricsPanel, InfoPanel, TrackInfo, ProfileEditor.
4. Settings: `Settings.svelte`, `settings/*`, `settingsIndex.ts` (keys + bilingual search,
   spec §4.5), `settingsView.ts`, hotkeys action names, `UpdatesSection`, `RemoteSettings`,
   `AutoMixPanel`, `OutputDevicePicker`.
5. History and Stats: `History.svelte`, `HistoryStats.svelte`, `historyTime.ts`, `historyChart.ts`.
6. Hi-Fi Rack: accessible names, menus, tooltips (legends stay English, I18N-D7).
7. Phone remote: `remote/**` through `remote.json`, `navigator.languages` resolution, `lang`.

## Phase 4 — Drafting (spec §7.3)

- Claude drafts 19 languages (batches per namespace, glossary first); `apply-draft.mjs`.
- DeepSeek V4.1 Flash drafts `zh-Hans` and `zh-Hant` (delegate task with the English catalog,
  notes, glossary and conventions); Claude cross-checks; second pass on disagreements;
  status `cross-checked`.
- `check.mjs` clean; `status.mjs --json` recorded.
- Greek review sheet handed to the owner.

- A-5 zoom: `[ui] zoom`, `set_zoom`, Ctrl+= / − / 0, shortcuts card, settings index.
