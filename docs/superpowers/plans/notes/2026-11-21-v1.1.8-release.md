## What ships

Changes since `v1.1.7`:

- `42e514b9` fix(queue): turning shuffle off restores the original order (#7). Each context
  track carries its place (`QueueItem::ordinal`, `#[serde(skip)]`: no IPC or phone-remote
  change); `Queue::unshuffle` sorts by it and goes on from the current track's place. Added
  tracks stay right after the current one, suggestions at the end.
- Persisted state: `session.json` items gain an optional `ordinal` (`SessionItem`, skipped when
  absent). Older sessions load as before (no places: shuffle off keeps their order); an older
  build reading a 1.1.8 session ignores the field. No config or locale-catalog change.
- `ace7a35a` and this release's bookkeeping: gate notes and smoke ticks.
