## What ships

Changes since `v1.1.10`:

- `931c3e70` fix(net): a GET gets one quick retry on a TLS failure (`TLS_GET_ATTEMPTS = 2`);
  writes still none (#10; `2026-11-23-profiles-loading-issue-10.md`).
- `44eb4531` fix(shell): the `tidal://` handler is detected, backed up and restored through
  the registry API, never `reg.exe`, so a Windows sign-out or restart no longer shows a
  "reg.exe - Application Error" and the official handler comes back. A `.reg` backup an older
  build left is imported once at startup (#15; `2026-11-27-scheme-logoff-issue-15.md`).
- `a355ffd6` feat(ui): filter boxes on Albums and on Playlists (root and folders, searching
  the folders below) (#14; `2026-11-27-library-filters-issue-14.md`). Seven new `app.json`
  messages, machine-drafted for the 23 shipped languages.
- No new IPC command, no config or persisted-state file change. The scheme backup moves from
  `tidal-scheme.reg` in the config folder to `HKCU\Software\OxiTide\tidal-scheme-backup`.
