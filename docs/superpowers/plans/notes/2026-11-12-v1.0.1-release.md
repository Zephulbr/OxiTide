# v1.0.1 release gate

- **Date:** 2026-11-12
- **Status:** Tagged; draft release built. Publishing and the in-app update check are the owner's.
- **Runbook:** `docs/release.md`. Notes: `docs/release-notes/v1.0.1.md`. Background: the v1 retro
  (`2026-11-11-v1-retro.md`).

## What ships

The only change to shipped code since `v1.0.0`: `tauri-plugin-updater` is built without its `zip`
feature (`c2f2f2f`), which removes the `zip` crate and its four advisories. Every other change in
`crates/` is inside `#[cfg(test)]` modules (checked against each file's `mod tests` line), plus CI,
docs and scripts. No audio, output or UI code changed.

## Gate

Each machine-record tick carries its id (`AGENTS.md`, Workflow).

- [ ] CI green on the version-bump commit — run: (id)
- [ ] Release run: `gates` (the full CI, first run of this job) green, then builds and the draft —
      run: (id)
- [ ] Draft contents: NSIS `.exe` + `.sig`, `.msi` + `.sig`, `.deb`, `.AppImage` + `.sig`,
      `latest.json` (version `1.0.1`, URLs on the `v1.0.1` tag), `SHA256SUMS.txt`, `PKGBUILD`;
      notes from `docs/release-notes/v1.0.1.md`.
- [ ] **Owner:** publish the draft.
- [ ] **Owner:** in-app update on the daily Windows install: Settings → System → Updates finds
      1.0.1, installs it, and the app restarts reporting 1.0.1. This is the updater of **1.0.0**
      (still with zip support) applying a bare installer, so it checks the release pipeline, not
      the zip-less updater.
- [ ] Optional (owner): the same on the Linux AppImage.
- **Not required:**
  - A perf corpus: no audio, output or UI code changed. The v1.0.0 corpus is still open in the
    retro.
  - A clean-machine install: the shipped change is the updater's build features. The in-app update
    runs the new installer anyway.

## After publishing

- [ ] `release/1.x` cut at `v1.0.1` (V2-D3): 1.x hotfixes land there and are tagged `v1.0.x` from
      it, then merged forward into `main`. `main` is V2 from here.
- [ ] The zip-less updater's own proof: a copy running **1.0.1** updates itself to the next 1.x
      release (1.0.2 or later). Record the result here and in the retro.
