## Owner checklist (Windows, real account)

### Album facts

- [ ] Open an album that has a release date/copyright/UPC → the facts row shows `Released`, `Copyright`, and `UPC` with the payload values; the `Volumes` fact appears for multi-volume albums; any absent field is simply omitted (no blank/broken cell).
- [ ] Confirm the facts row shows release date/copyright/UPC/volume count and **never shows a label** — the public v2 payload exposes none (Task 0 Decision 2).
- [ ] Open a single → the facts row is minimal or absent, and the header/stats/table layout is unaffected.
- [ ] Block only the album-info request in WebView2 devtools (request blocking for `*/openapi/v2/albums/*`) and open an album → album + tracks still load; the facts row is simply absent, no error surface.

### Multi-volume

- [ ] Open a multi-volume album (e.g. "Rubber Soul (Super Deluxe)", 4 volumes) → `Volume N` headings appear with disc-scoped numbering (1..n per volume).
- [ ] Sort or filter the album table → grouping falls back to the flat table with normal continuous numbering; clearing the sort/filter restores the volume headings.
- [ ] Single-volume albums are unchanged (no headings, same table as before this plan).
- [ ] A multi-volume payload with absent/partial/zero `volumeNumber`s → no track is hidden or reordered.

### Info tab

- [ ] Play a track and open Now Playing → the spine shows Lyrics / Next up / Info.
- [ ] Select Info → track metadata loads once and shows the album link, artist(s), duration, and Quality when the payload carries one.
- [ ] Leave and reopen the same track's Info → no refetch/spinner (per-session cache); open a different track → its info loads fresh.
- [ ] Click the album link or an artist link → navigates to that route and closes the Now Playing overlay.
- [ ] Keyboard: Up/Down/Home/End move the tablist roving focus and switching tabs swaps the panel (ARIA tabs from birth, spec §6.2).

### Credits

- [ ] A track with credits lists role groups (e.g. Producer, Banjo) in payload order, with contributor names separated within each role.
- [ ] Contributors that carry an artist id render as links; clicking one navigates to the artist page and closes the overlay. Contributors without an id render as plain text.
- [ ] A track without credits shows "No credits available for this track." — no error surface and no stuck spinner.
- [ ] Open a track with many credits (e.g. "Draw You Out", `tracks/564178214`) and confirm the first-page credit list renders correctly; note that tracks with more than 20 credits show page 1 only (recorded follow-up in the Task 0 note — no error expected).
- [ ] Credits worked against the live account (Task 0 decided accessible). If a region/account shows no credits, record it here and note the Info tab is metadata-only (the §5.3 fallback).

### Track info menu

- [ ] Open a track row's menu (right-click) → "Track info" is present.
- [ ] Choose "Track info" on the **currently playing** track → Now Playing opens on the Info tab.
- [ ] Choose "Track info" on any **other** row → a modal titled "Track info" opens with the same panel.
- [ ] Escape closes the modal; clicking the backdrop closes it; both restore focus to the originating control. The header ✕ closes it too.
- [ ] Click an album/artist link inside the modal → navigates and closes the modal.

### Failure paths

- [ ] Disconnect the network and open Info on a track never opened this session → the track error state appears with Retry (no stuck "Loading track info…").
- [ ] Restore the network, press Retry → track info and credits both load.
- [ ] Open track A's Info, then immediately open track B's Info while A is still loading → only B's data ever paints (no flash of A).
- [ ] Fail only the credits call while metadata succeeds → the facts still render and the credits section shows its inline error + Retry.
