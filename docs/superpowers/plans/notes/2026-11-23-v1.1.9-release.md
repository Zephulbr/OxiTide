## What ships

Changes since `v1.1.8`:

- `34cc04de` fix(paging): `get_all_pages` logs each walk when it ends (items, windows, empty
  windows, TIDAL's total, ms) and a long one's total before it starts; path ids masked
  (`users/*/favorites/artists`).
- `ed9643af` fix(paging): a walk with a known total stops after 10 empty windows in a row
  (1,000 rows at 100 a window), with a WARN; offsets are made a group at a time. Issue #4's
  read-past-empty-windows rule holds below that.
- `093225d8` fix(ui): Profiles shows the own card while the favorites load or after they fail;
  `viewCache` shares a running fetch for `JOIN_MS` (60 s) only.
- Added after the bump commit `8ad8406a` (owner, 2026-11-23, from the #10 reporter's startup
  `InvalidContentType`; the tag was held for it):
  - fix(net): reqwest 0.12 trusts the OS certificate store as well as the bundled Mozilla roots
    (`rustls-tls-native-roots` beside `rustls-tls`; reqwest merges both). HTTPS-scanning
    antivirus and corporate proxies re-sign with a root they install in the OS store.
    `oxitide_tidal::build_client` (and the audio fetcher) fall back to the bundled roots when
    the OS store is unreadable. The updater needed no change: tauri-plugin-updater 2.13 uses
    reqwest 0.13, whose rustls backend already verifies through `rustls-platform-verifier`.
    Chosen over `native-tls` (a second TLS stack, OpenSSL on Linux) and over
    `rustls-platform-verifier` (reqwest 0.12 has no feature for it; it is reqwest 0.13's
    default, a later upgrade).
  - fix(net): a TLS failure (any `rustls::Error` in reqwest's chain, `io::Error` opened) is
    `Error::Tls`, "tls error: …". It is not retried per request (reads or writes), stays
    `is_transient` (offline start, cached playback, resume, a refresh failure is not a
    logout), and the startup offline line names the likely interference. The UI shows
    `error.secureConnection`, drafted in all 23 languages (machine).
  - chore(deps): `cookie` 0.18.3 (RUSTSEC-2026-0594) and `url` 2.5.9 (RUSTSEC-2026-0592), both
    advisories new on 2026-11-23; they failed Audit run 45252553635 on `8ad8406a`.
- No IPC, config or persisted-state change. One new locale message (`error.secureConnection`).
