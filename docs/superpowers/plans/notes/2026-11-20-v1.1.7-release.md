## What ships

Changes since `v1.1.6`:

- `9d05e366` fix(play): a click plays at once while a long list loads (#7). Tracks, a
  playlist and an artist's All tracks play the loaded rows and add the rest once loaded; the
  table no longer disables every row while a play waits. Queue: `extend_context` is gated on a
  context id (a new play, restore or clear) instead of the queue revision, lands before
  Autoplay's suggestions, and merges a shuffled rest in one linear pass. IPC change:
  `play_tracks` returns the context id (it returned the queue revision; only the search play
  read it), `queue_extend_context(items, context)` returns whether it applied. Phone remote
  unchanged (the command is `NOT_EXPOSED`). Known gap, left for `main`: phone plays do not
  count as newer for a desktop play still waiting for its list.
- `2236966d` feat(filter): list filters ignore punctuation and accents (desktop and phone).
- `814991a5` feat(remote): the phone queue marks the playing and played tracks and opens on the
  playing one.
- `68c5ee42` docs(v1.1.6): gate note bookkeeping.
- No config, persisted-state or locale-catalog change.
