# v1.1.0 smoke checklist (languages + accessibility)

- **Date:** 2026-11-14
- **Status:** Open (owner). Everything below needs the real app, a signed-in account and a
  person; the automated gates are in the release gate note (`2026-11-14-v1.1.0-release.md`).
- **Spec:** `2026-11-12-oxitide-v1.1-i18n-a11y-design.md` §13. Plan:
  `2026-11-12-v1.1-i18n-a11y.md` (this note closes the open owner items of Phases 1, 2, 4
  and 5).

Run the dev build (`npm --prefix ui run app:dev`) unless an item says installer. Tick each
item with one line on what was exercised (`AGENTS.md`, Workflow); a failure gets a line and
a follow-up, not a tick.

## 1. Language switch (Phase 1)

- [ ] Settings → Appearance → Look & feel → **Language** → Deutsch: the page re-renders at
      once; the player bar, the window title, the skip link (Tab from the top) and a toast's
      close button are German.
- [ ] Tray menu (Show / Hide, Play / Pause, Next, Previous, Quit) and the taskbar thumbnail
      buttons' tooltips are German.
- [ ] Quit and restart: the app opens in German with no English flash.
- [ ] Back to **System**: the app follows Windows' display language again (English on an
      English Windows).
- [ ] The **Help translate** link opens `CONTRIBUTING.md#translating` on GitHub (it 404s
      until the 1.1 docs are on `main` there).

## 2. Pseudo-locale walk (Phase 2)

`node scripts/i18n/pseudo.mjs` once, then pick the pseudo-locale (`en-XA`, dev builds only)
in the language picker. Every string should be accented and bracketed: plain English is a
missed extraction, a cut-off `⟧` is clipping.

- [ ] Shell: sidebar, player bar, queue, Now Playing, mini player, window controls, toasts.
- [ ] Lists and menus: track tables (headers, sort menu, selection count), every context
      menu, the queue's menus, drag-to-playlist feedback.
- [ ] Pages: Home, Explore and search, album, artist, playlist, mix, radio, Profiles,
      Playlists and folders, My Collection, Save for Later, History and Stats, Feed.
- [ ] Settings: every tab, the settings search (type a German word and an English one), every
      dialog (output device edit, collaborators, profile editor, confirmations).
- [ ] Hi-Fi Rack: region names, tooltips and content are bracketed; painted legends stay
      English (I18N-D7, §6 below).
- [ ] Phone remote: open it on a phone set to German, then to a language without a catalog
      (it falls back to English).

## 3. Overflow and fonts

- [ ] German and Finnish: Settings (labels and segmented controls), the player bar at the
      minimum window size, track table headers, context menus, the mini player. Long words
      end in "…" or wrap; nothing overlaps.
- [ ] Japanese and Chinese (Traditional): text uses Yu Gothic UI / Microsoft JhengHei UI, not a
      fallback with mixed shapes; Japanese lines never start with 、。」; Korean headings
      break between words.
- [ ] Polish, Czech, Romanian (ș ț), Turkish, Ukrainian, Russian, Greek: no tofu boxes; the
      accented letters match the surrounding font (the latin-ext, Cyrillic and Greek subsets
      load).
- [ ] Dates, counts and durations follow the language (German: "11. Feb. 2014", "1,1 Mio.",
      "3 Std. 05 Min."; Japanese: "2014年2月11日", "1.2万").

## 4. Greek review (owner)

- [ ] `node scripts/i18n/review-sheet.mjs el`, read through, answer the ten questions in
      `2026-11-14-v1.1-drafting.md`, fix in `ui/src/locales/el/*.json`, then
      `node scripts/i18n/sync.mjs --review el` to mark the rest reviewed.

## 5. Accessibility (Phase 5)

- [ ] **Contrast theme (A-3).** Windows Settings → Accessibility → Contrast themes → Night
      sky, then Desert. In each of Atmosphere, Studio and Rack:
      - focus rings show on Tab everywhere;
      - the seek bar shows played vs unplayed and its thumb; the volume level shows; Settings
        sliders, toggles (on vs off) and segmented controls (the chosen segment) read;
      - a selected track row is framed, the playing row's title is highlighted, the queue's
        current row is framed, the now-playing disc mark shows;
      - the open sidebar page, Settings tab and Now Playing tab are framed;
      - dragging a track over a playlist frames it, and the drop line shows in lists and the
        queue;
      - no cover backdrop, grain or colour wash; icons follow the text colour;
      - Rack: usable (keys, tabs, knob, meters readable), skin not expected.
- [ ] **Track announcements (A-4), NVDA on.** Play a track from a list, press Next, Previous,
      double-click a queue row: NVDA says "Now playing: {title} by {artists}" once each. Let
      a track end on its own: nothing is said. Repeat in one other language (German).
- [ ] **Zoom (A-5).** Ctrl+= to 150 %, Ctrl+− to 80 %, Ctrl+0 back to 100 %; Settings →
      Appearance → Typography & layout → Zoom follows and the slider does the same. Restart:
      the zoom holds with no 100 % flash. At 150 % and the minimum window size: the player
      bar, queue, Settings and Now Playing lay out without overlap. The mini player opens at
      100 % and the full window returns to the chosen zoom. Zoom keys work on the sign-in
      screen and with the caret in a search field. The Settings → Shortcuts card lists
      them.
- [ ] **9.4 scripts in one language.** Re-run the 9.4 keyboard walk and NVDA script
      (`DONE-plan9-smoke.md`) in German: labels, live regions (selection count, buffering) and
      the skip link speak German.

## 6. Decisions to confirm

- [ ] **I18N-D7:** Rack's painted legends (nameplates, silkscreen, key captions, VFD
      annotations) stay English. Confirm or list the ones to translate.
- [ ] **A-5 range and default:** 80–150 % in steps of 10, default 100 %, the mini player
      always at 100 %. Confirm or change.
- [ ] **TIDAL locale spike:** the two-minute browser check in
      `2026-11-13-tidal-locale-spike.md`. If titles translate, it becomes a 1.1.x follow-up.
