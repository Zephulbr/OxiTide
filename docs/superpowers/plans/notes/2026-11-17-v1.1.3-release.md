## What ships

- Shuffle + Repeat All: each pass plays a new order. When the last track becomes current
  (track ended, Next, a skip, a queue jump, or Repeat All turned on there), the tracks before it
  are reshuffled (`Queue::prepare_next_pass`), so the next pass's first track is preloaded as
  usual and the wrap stays gapless. Lists of two or fewer keep their order. Engine only: no
  command, config, UI or TIDAL-client change.
