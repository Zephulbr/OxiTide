OxiTide 1.1.11 adds a search box to Albums and Playlists, stops a "reg.exe" error when you sign out of or restart Windows with OxiTide open, and retries a TIDAL request once when a secure connection briefly fails. Everything else is the same as in 1.1.10.

> OxiTide is an unofficial, third-party project. It is not affiliated with, endorsed by, or connected to TIDAL. A paid TIDAL subscription is required. OxiTide plays only what your own account can already stream.

## New

- **Search your Albums and Playlists** ([#14](https://github.com/Zephulbr/OxiTide/issues/14)). Albums has a filter box next to the sort menu that matches album titles and artist names; case, accents and punctuation are ignored, so "beyonce" finds Beyoncé. On Playlists the box matches playlist and folder names in the folder you are in and every folder inside it, so a playlist filed in a folder is found from **All playlists**; its folder shows under its name.

## Fixes

- **No "reg.exe" error when you sign out or restart** ([#15](https://github.com/Zephulbr/OxiTide/issues/15)). When OxiTide closes, it gives the `tidal://` link back to the official TIDAL app if you have it installed. It used to do that by starting `reg.exe`, which Windows does not allow while you sign out or restart, so you saw an "Application Error" dialog and the TIDAL app did not get its link back. OxiTide now makes the change itself, without starting another program. If an earlier sign-out left the link with OxiTide, the first start of 1.1.11 puts it right.
- **A brief secure-connection failure no longer shows an error at once** ([#10](https://github.com/Zephulbr/OxiTide/issues/10)). Where something on the network (such as antivirus that scans HTTPS) occasionally interferes with a connection to TIDAL, a page load is now retried once before "Couldn't connect securely to TIDAL" shows. Changes you make (likes, playlist edits) are still never sent twice.

## Install

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `OxiTide_1.1.11_x64-setup.exe` (per user, recommended) or the `.msi` (per machine) |
| Linux (x86_64) | `.AppImage` or `.deb`; `PKGBUILD` for Arch (AUR recipe) |

Check downloads against `SHA256SUMS.txt`. An installed 0.3 or later copy offers the update in **Settings → System → Updates**. deb and AUR installs update through the package manager.

## Known limits and Linux

Unchanged from 1.1: Windows builds are not code-signed (SmartScreen: **More info → Run anyway** after checking the hash), the phone remote uses plain HTTP on your local network, and Linux is a work in progress with the known issues listed in the [1.0 release notes](https://github.com/Zephulbr/OxiTide/releases/tag/v1.0.0).
