OxiTide 1.1.10 fixes another way the Profiles page could stay on "Loading…", and keeps a page that fails to display from freezing the app. Everything else is the same as in 1.1.9.

> OxiTide is an unofficial, third-party project. It is not affiliated with, endorsed by, or connected to TIDAL. A paid TIDAL subscription is required. OxiTide plays only what your own account can already stream.

## Fixes

- **Profiles shows the artists you follow even if TIDAL lists one twice** ([#10](https://github.com/Zephulbr/OxiTide/issues/10)). If the list from TIDAL contained the same artist twice (which may happen when many were followed at the same moment, such as after an import from another service), Profiles stopped while drawing it and stayed on "Loading…". Your followed artists, albums and tracks now show each item once.
- **A page that fails to display says so.** If a page ever runs into a problem while drawing, it now shows an error with a **Retry** button instead of freezing, and the rest of the app keeps working. The problem is written to the log and appears under "Recent problems" in **Settings → Diagnostics → Copy diagnostics**, without account or playlist ids.

## Install

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `OxiTide_1.1.10_x64-setup.exe` (per user, recommended) or the `.msi` (per machine) |
| Linux (x86_64) | `.AppImage` or `.deb`; `PKGBUILD` for Arch (AUR recipe) |

Check downloads against `SHA256SUMS.txt`. An installed 0.3 or later copy offers the update in **Settings → System → Updates**. deb and AUR installs update through the package manager.

## Known limits and Linux

Unchanged from 1.1: Windows builds are not code-signed (SmartScreen: **More info → Run anyway** after checking the hash), the phone remote uses plain HTTP on your local network, and Linux is a work in progress with the known issues listed in the [1.0 release notes](https://github.com/Zephulbr/OxiTide/releases/tag/v1.0.0).
