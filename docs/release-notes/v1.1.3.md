OxiTide 1.1.3 gives Shuffle with Repeat All a new order on every pass. Everything else is the same as in 1.1.2.

> OxiTide is an unofficial, third-party project. It is not affiliated with, endorsed by, or connected to TIDAL. A paid TIDAL subscription is required. OxiTide plays only what your own account can already stream.

## Changes

- **A new order on every repeat.** With shuffle and **Repeat All** both on, each time the queue starts over it plays in a fresh shuffled order, instead of repeating the same sequence. The song that just ended never comes straight back, and the loop stays gapless. The new order is picked as the last song of a pass starts, so you'll see the queue's earlier rows rearrange at that point.

## Install

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `OxiTide_1.1.3_x64-setup.exe` (per user, recommended) or the `.msi` (per machine) |
| Linux (x86_64) | `.AppImage` or `.deb`; `PKGBUILD` for Arch (AUR recipe) |

Check downloads against `SHA256SUMS.txt`. An installed 0.3 or later copy offers the update in **Settings → System → Updates**. deb and AUR installs update through the package manager.

## Known limits and Linux

Unchanged from 1.1: Windows builds are not code-signed (SmartScreen: **More info → Run anyway** after checking the hash), the phone remote uses plain HTTP on your local network, and Linux is a work in progress with the known issues listed in the [1.0 release notes](https://github.com/Zephulbr/OxiTide/releases/tag/v1.0.0).
