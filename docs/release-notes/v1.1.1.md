OxiTide 1.1.1 makes search easier to find. Playback, output and everything else are the same as in 1.1.

> OxiTide is an unofficial, third-party project. It is not affiliated with, endorsed by, or connected to TIDAL. A paid TIDAL subscription is required. OxiTide plays only what your own account can already stream.

## Changes

- **Search on Home.** Home has a search field at the top right, level with the greeting. Press Enter, or pick a recent search, to see the results on Explore; Back returns to Home. `Ctrl+F` and `/` jump to it while you are on Home.
- **Explore shows it searches.** The sidebar's Explore item now has a magnifier icon, and its tooltip names the shortcut ("Explore and search (Ctrl+F)").
- **Hide it if you prefer.** **Settings → Appearance → Typography & layout → Search bar on Home** turns the Home field off (it is on by default). Explore always has its search.
- The new text is machine-translated into all 23 languages, like the rest of 1.1.

## Install

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `OxiTide_1.1.1_x64-setup.exe` (per user, recommended) or the `.msi` (per machine) |
| Linux (x86_64) | `.AppImage` or `.deb`; `PKGBUILD` for Arch (AUR recipe) |

Check downloads against `SHA256SUMS.txt`. An installed 0.3 or later copy offers the update in **Settings → System → Updates**. deb and AUR installs update through the package manager.

## Known limits and Linux

Unchanged from 1.1: Windows builds are not code-signed (SmartScreen: **More info → Run anyway** after checking the hash), the phone remote uses plain HTTP on your local network, and Linux is a work in progress with the known issues listed in the [1.0 release notes](https://github.com/Zephulbr/OxiTide/releases/tag/v1.0.0).
