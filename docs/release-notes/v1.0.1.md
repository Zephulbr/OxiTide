OxiTide 1.0.1 is a maintenance release. It changes how updates are applied under the hood and removes the one security advisory that 1.0 shipped with accepted. Playback, output and the interface are the same as in 1.0.

> OxiTide is an unofficial, third-party project. It is not affiliated with, endorsed by, or connected to TIDAL. A paid TIDAL subscription is required. OxiTide plays only what your own account can already stream.

## Changes

- **No more accepted advisory.** 1.0 listed `zip` 4.6.1 (RUSTSEC-2026-0367/0368/0369) as an accepted advisory, pulled in by Tauri's updater; a fourth (RUSTSEC-2026-0429) has been published since. OxiTide's updates are never archives (Windows installs the setup or `.msi` file directly, and the Linux AppImage is replaced as a whole), so the updater is now built without archive support at all. The `zip` library is gone, and with it all four advisories.
- **Release checks.** A release is now built only after the full test suite passes on the exact commit being released, on Windows and Linux. Behind the scenes, the audio engine's tests were made reliable on slow build machines, and dependencies are checked for security advisories every week.

## Install

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `OxiTide_1.0.1_x64-setup.exe` (per user, recommended) or the `.msi` (per machine) |
| Linux (x86_64) | `.AppImage` or `.deb`; `PKGBUILD` for Arch (AUR recipe) |

Check downloads against `SHA256SUMS.txt`. An installed 0.3 or later copy offers the update in **Settings → System → Updates**. deb and AUR installs update through the package manager.

## Known limits and Linux

Unchanged from 1.0, apart from the advisory above: Windows builds are not code-signed (SmartScreen: **More info → Run anyway** after checking the hash), the phone remote uses plain HTTP on your local network, and Linux is a work in progress with the known issues listed in the [1.0 release notes](https://github.com/Zephulbr/OxiTide/releases/tag/v1.0.0).
