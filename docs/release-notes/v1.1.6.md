OxiTide 1.1.6 fixes long lists that stopped short when they held unavailable tracks, and makes a tapped song on the phone play with the rest of its list. Everything else is the same as in 1.1.5.

> OxiTide is an unofficial, third-party project. It is not affiliated with, endorsed by, or connected to TIDAL. A paid TIDAL subscription is required. OxiTide plays only what your own account can already stream.

## Fixes

- **Lists with unavailable tracks load to the end.** TIDAL counts tracks that are no longer available but never sends them. When enough of them sat together, the phone remote stopped loading your Tracks or a playlist there, so its filter missed older songs ([#4](https://github.com/Zephulbr/OxiTide/issues/4)). The phone could also show a song twice. The desktop app could stop the same way on a playlist. Both now read the whole list.
- **A tapped song on the phone plays with the whole list.** Tapping a song on the phone queued only the part of the list you had scrolled through, so with shuffle on you mostly heard your newest favorites. This may be what [#7](https://github.com/Zephulbr/OxiTide/issues/7) describes; that report is still open. Tapping a song now loads the rest of the list first, as Play and Shuffle already did, and so do both "Add all" buttons. A tapped song in a list longer than 5,000 tracks also plays the right song now.
- **Phone remote:**
  - Lyrics no longer reload, and the artist and album links no longer flicker, when you pause or change the volume.
  - Clearing the search box while a search is running no longer brings its results back.
  - The Retry button on a playback error is now translated.
  - Adding more than 5,000 tracks to a playlist adds the first 5,000 instead of failing.

## Install

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `OxiTide_1.1.6_x64-setup.exe` (per user, recommended) or the `.msi` (per machine) |
| Linux (x86_64) | `.AppImage` or `.deb`; `PKGBUILD` for Arch (AUR recipe) |

Check downloads against `SHA256SUMS.txt`. An installed 0.3 or later copy offers the update in **Settings → System → Updates**. deb and AUR installs update through the package manager.

## Known limits and Linux

Unchanged from 1.1: Windows builds are not code-signed (SmartScreen: **More info → Run anyway** after checking the hash), the phone remote uses plain HTTP on your local network, and Linux is a work in progress with the known issues listed in the [1.0 release notes](https://github.com/Zephulbr/OxiTide/releases/tag/v1.0.0).
